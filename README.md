# skills

Agent skills, grouped by discipline. Each group keeps its skills under `<group>/skills/<name>/SKILL.md`.

- [eng](./eng/) - engineering workflows and principles
- [design](./design/) - product and visual design
- [writing](./writing/) - prose, docs, and communication
- [skill-master](./skill-master/) - authoring and improving skills
- [orchestrator](./orchestrator/) - coordinating multiple agents across a task
- [everyday](./everyday/) - general skills anyone uses daily, often called by other skills

## Install

```
npx skills add cychien/skills
```

Add `--list` to see every skill, or `--skill <name>` to install one. Run `npx skills update` to pull the latest.
